# Contributing

## Principles

1. Keep the network finance-led and interdisciplinary by design.
2. Use only public, synthetic, historical, or approved anonymized information.
3. Do not represent student work as investment, legal, tax, audit, lending, appraisal, or other professional advice.
4. Preserve faculty control over scope, milestones, assessment, and student communication.
5. Do not name a person as committed until participation is confirmed.
6. Record material model assumptions, source dates, limitations, and AI use.

## Change process

- Open an issue using the appropriate template.
- Link the proposed change to a practicum, pilot milestone, or governance requirement.
- Use a feature branch.
- Submit a pull request with evidence that the change was reviewed.
- Do not merge changes containing confidential data.
