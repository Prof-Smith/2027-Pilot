# Deployment

## GitHub Pages

This repository includes two deployment options.

### GitHub Actions, recommended

1. Create a GitHub repository named `finance-applied-practicum-network`.
2. Upload the contents of this package to the repository root.
3. In repository settings, open Pages and select **GitHub Actions** as the source.
4. Push to the `main` branch. The workflow in `.github/workflows/pages.yml` publishes the `site/` directory.

### Deploy from branch

The root `index.html` is also included for platforms configured to publish directly from the repository root.

## Local preview

Open `index.html` directly in a browser. The enhanced launch experience is self-contained and has no external asset dependencies.

## Before public release

- Obtain approval for official Saint Leo University branding and logos.
- Confirm which named stakeholders have agreed to participate.
- Do not commit confidential partner or student data.
- Review partner names and marks for authorized public use.
