# Saint Leo Finance Applied Practicum Network

A finance-led, industry-guided, faculty-supervised ecosystem for Spring 2027 applied learning.

## Founding proposition

Professional access is valuable. Professional readiness is transformational.

The network converts relationships with professional societies, alumni, and industry partners into bounded finance decisions that students analyze, model, defend, revise, and document.

## Spring 2027 recommendation

**Preferred founding pilot:** Embarc Collective, Venture Finance & Strategic Growth  
**Alternate pilot:** TBAFP / AFP, Corporate Treasury & FP&A

## Five professional gateways

1. CFA Society Tampa Bay: investments and markets
2. TBAFP / AFP: treasury and corporate finance
3. NIRI Florida: investor relations and capital-markets communication
4. CCIM Florida West Coast: real assets and commercial finance
5. Embarc Collective: venture finance and strategic growth

## Repository map

- `site/`: GitHub Pages-ready public microsite
- `practicums/`: one-page partner briefs
- `pilot/`: Spring 2027 launch architecture and scorecard
- `governance/`: roles, safeguards, and approval controls
- `templates/`: reusable case, sponsor, student, and reviewer templates
- `data/`: synthetic-data schemas and sample datasets
- `docs/`: prospectus and internal strategy material
- `.github/`: issue templates, pull-request template, and Pages workflow

## Local preview

Open `site/index.html` in a browser, or run:

```bash
python -m http.server 8000 -d site
```

Then visit `http://localhost:8000`.

## GitHub Pages

The included workflow publishes the `site/` directory when changes are pushed to `main`. In repository settings, choose **GitHub Actions** as the Pages source.

## Operating standard

Each pilot should have:

- one consequential but bounded finance decision;
- one professional-society or ecosystem sponsor;
- one finance faculty lead with academic control;
- one alumni or practitioner case lead;
- two practitioner reviewers;
- three partner touchpoints: launch, midpoint challenge, and final panel;
- documented evidence of student capability, partner value, and repeatability.
